airdcpp web client adl-search extension
Lists all the unwanted files in your own share (Bonus: Also files with permission issues!)

1. Get a good ADLSearch.xml to use (not included!)
2. Place ADLSearch.xml in your /config folder
3. Gp to AirDC  web client > Settings > Extensiuons > Extension catalog > Install from url > Paste the above link to the latest version.
4. Click "Manage installed", and set the plugins settings as you want.
5. Profit!

Available commands:
- /adl scan - Scans your share
- /adl matches - Shows your matched files (bonus: also files with permission errors)
- /adl list - a small quick info posten in the chat (for your eyes only)
- /adl reload - Reloads the ADLSearch.xml (if you make changes to it and dont want to restart the client)

You can also access the above funtions trough the Manage dropdown for the extension.
