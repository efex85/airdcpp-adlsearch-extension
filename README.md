# airdcpp-adlsearch-extension

Quick install link: https://raw.githubusercontent.com/efex85/airdcpp-adlsearch-extension/main/quickinstall/airdcpp-adl-checker-1.0.3.tgz

ADLSearch.xml not included! Find your own and put it in the /config folder.

1. Install (Settings > Extensions > Extension catalog > Install from URL > See url to latest release above.
2. Go back to "Manage installed", click "Configure" and set the settings you want.
3. Profit!

You can run a manual scan at will, or show matches from the latest scan trough the Manage-dropdown. Check the events log for results.
